## 🌐 開發環境配置

### Android 模擬器網路問題解決方案

#### 問題描述
Android 模擬器無法訪問 `127.0.0.1` 或 `localhost`，需要使用主機的實際 IP 地址。

#### 解決方案
1. **自動 IP 檢測**: `run_dev_environments.sh` 腳本會自動檢測主機 IP
2. **配置檔案更新**: 自動更新 `android_emulator.json` 中的 IP 地址
3. **備份機制**: 每次更新前會備份原始配置檔案

#### 網路地址映射
- `127.0.0.1` / `localhost` → 模擬器內部
- `10.0.2.2` → 主機的 `127.0.0.1` (理論上，但可能不工作)
- `192.168.1.x` → 主機的實際 IP (推薦使用)

## 🚀 使用方法

### 啟動 Android 模擬器開發環境
```bash
./scripts/run_dev_environments.sh android
```

腳本會自動：
1. 檢測主機 IP 地址
2. 更新配置檔案
3. 啟動 Flutter 應用程式

### 手動測試 API 連接
```bash
# 測試本地連接
curl -X POST http://127.0.0.1:8888/here4help/backend/api/auth/login.php \
  -H "Content-Type: application/json" \
  -d '{"email":"michael@test.com","password":"test123"}'

# 測試主機 IP 連接
curl -X POST http://192.168.1.103:8888/here4help/backend/api/auth/login.php \
  -H "Content-Type: application/json" \
  -d '{"email":"michael@test.com","password":"test123"}'
```

## 🔧 故障排除

### 常見問題

#### 1. 登入失敗 "Invalid email or password"
- **原因**: 密碼錯誤或用戶不存在
- **解決**: 確認使用正確的測試憑證 (`michael@test.com` / `test123`)

#### 2. 網路連接失敗
- **原因**: Android 模擬器無法訪問主機服務
- **解決**: 
  1. 確認 MAMP 服務正在運行
  2. 檢查防火牆設置
  3. 使用腳本自動更新 IP 地址

#### 3. API 端點無法訪問
- **原因**: 後端服務未啟動或配置錯誤
- **檢查**: 
  ```bash
  # 檢查服務狀態
  lsof -i :8888
  
  # 測試 API 端點
  curl http://localhost:8888/here4help/backend/api/auth/login.php
  ```

### 配置檔案位置
- **Android 模擬器**: `assets/app_env/android_emulator.json`
- **iOS 模擬器**: `assets/app_env/ios_simulator.json`
- **Web 開發**: `assets/app_env/development.json`
