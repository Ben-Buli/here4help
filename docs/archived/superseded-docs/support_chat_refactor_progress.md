## 🎯 專案目標

1. **單一進行中事件**: 每個用戶同時只能有一個進行中的客服事件
2. **Timeline 進度顯示**: 三點式進度條顯示客服狀態和時間戳記
3. **統一聊天室架構**: 沿用現有聊天室架構，支援客服類型
4. **管理員接手機制**: 管理員可透過後台 claim 接手客服事件
5. **評分結案功能**: 用戶可評分並結案客服事件
