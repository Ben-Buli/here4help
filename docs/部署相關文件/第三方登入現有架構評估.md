### 🚨 **本機測試 vs 部署環境問題**

#### **本機測試限制**
1. **OAuth 回調 URL 限制**：
   - Google/Facebook/Apple 需要註冊的回調 URL
   - 本機 `localhost:8888` 無法被外部服務訪問
   - 需要使用 ngrok 或類似工具建立隧道

2. **HTTPS 要求**：
   - Apple Sign-In 要求 HTTPS
   - Facebook 某些功能需要 HTTPS
   - 本機測試需要自簽憑證或 ngrok

3. **憑證驗證**：
   - 生產環境憑證無法在本機使用
   - 需要建立測試專案和測試憑證

#### **無法在本機測試的功能**
1. **真實的 OAuth 流程**：需要外部可訪問的 URL
2. **生產環境安全設定**：CORS、HTTPS 等
3. **App Store/Google Play 整合**：需要真實的 Bundle ID
4. **推送通知**：需要生產環境憑證
