# 平台網路分流配置指南

## 🌍 **平台分流概述**

不同平台需要使用不同的網路地址來訪問後端服務：

| 平台 | 基礎地址 | 實際地址 | 說明 |
|------|----------|----------|------|
| **Android 模擬器** | `127.0.0.1` | `10.0.2.2` | Android 模擬器自動轉換 |
| **iOS 模擬器** | `127.0.0.1` | `127.0.0.1` | iOS 模擬器保持原地址 |
| **Web 瀏覽器** | `127.0.0.1` | `127.0.0.1` | Web 平台保持原地址 |
| **實體設備** | `127.0.0.1` | `127.0.0.1` | 實體設備保持原地址 |

## 🔧 **分流邏輯實現**

### **1. 環境配置管理器**

#### 檔案：`lib/config/environment_config.dart`

**核心分流邏輯**：
```dart
/// 檢測是否為 Android 模擬器
static bool _isAndroidEmulator() {
  const androidEmulator = bool.fromEnvironment('ANDROID_EMULATOR', defaultValue: false);
  if (androidEmulator) {
    debugPrint('🔧 檢測到 ANDROID_EMULATOR 環境變數');
    return true;
  }
  
  // 在 Android 平台上，默認使用模擬器配置
  if (!kIsWeb) {
    debugPrint('🔧 檢測到 Android 平台，使用模擬器配置');
    return true;
  }
  return false;
}

/// 獲取正確的網路地址
static String _getNetworkAddress(String baseUrl) {
  // Android 模擬器使用 10.0.2.2
  if (_isAndroidEmulator()) {
    debugPrint('🔧 Android 模擬器檢測到，將地址轉換為 10.0.2.2');
    return baseUrl.replaceAll('127.0.0.1', '10.0.2.2').replaceAll('localhost', '10.0.2.2');
  }
  
  // iOS 模擬器和 Web 使用原始地址
  return baseUrl;
}
```

## 🚀 **啟動方式**

### **1. Android 模擬器**

#### **使用啟動腳本**
```bash
chmod +x start_android_emulator.sh
./start_android_emulator.sh
```

#### **手動啟動**
```bash
flutter run -d android \
  --dart-define=ENVIRONMENT=development \
  --dart-define=API_BASE_URL=http://10.0.2.2:8888/here4help \
  --dart-define=SOCKET_URL=http://10.0.2.2:3001 \
  --dart-define=IMAGE_BASE_URL=http://10.0.2.2:8888/here4help \
  --dart-define=DEBUG_MODE=true \
  --dart-define=LOG_LEVEL=debug \
  --dart-define=ANDROID_EMULATOR=true
```

### **2. iOS 模擬器**

#### **使用啟動腳本**
```bash
chmod +x start_ios_simulator.sh
./start_ios_simulator.sh
```

#### **手動啟動**
```bash
flutter run -d ios \
  --dart-define=ENVIRONMENT=development \
  --dart-define=API_BASE_URL=http://localhost:8888/here4help \
  --dart-define=SOCKET_URL=http://localhost:3001 \
  --dart-define=IMAGE_BASE_URL=http://localhost:8888/here4help \
  --dart-define=DEBUG_MODE=true \
  --dart-define=LOG_LEVEL=debug \
  --dart-define=IOS_SIMULATOR=true
```

### **3. Web 平台**

## 🔍 **檢測邏輯**

### **平台檢測優先級**

1. **環境變數檢測**：優先檢查 `ANDROID_EMULATOR` 和 `IOS_SIMULATOR` 環境變數
2. **平台檢測**：根據 Flutter 平台 API 檢測
3. **預設配置**：如果無法檢測，使用預設配置

### **網路地址轉換**

```dart
// 基礎地址（所有平台都使用 localhost 作為基礎）
String baseUrl = "http://localhost:8888/here4help";

// Android 模擬器轉換
if (_isAndroidEmulator()) {
  baseUrl = baseUrl.replaceAll('localhost', '10.0.2.2');
}

// iOS 模擬器和 Web 保持 localhost
// baseUrl 保持不變
```

## 🎯 **使用建議**

### **1. 開發時**
- 使用對應平台的啟動腳本
- 腳本會自動檢查後端服務狀態
- 提供詳細的錯誤信息

### **2. 測試時**
- 確保後端服務運行在 `localhost:8888`
- 確保 Socket.IO 服務運行在 `localhost:3001`
- 使用正確的平台檢測標記

### **3. 部署時**
- 更新生產環境配置
- 使用實際的伺服器地址
- 移除開發環境的調試標記

## 📝 **故障排除**

### **常見問題**

#### **1. Android 模擬器無法連接**
```bash
# 檢查後端服務
curl -s http://localhost:8888/here4help/backend/api/auth/login.php

# 檢查 Android 模擬器網路
adb shell ping 10.0.2.2
```

#### **2. iOS 模擬器無法連接**
```bash
# 檢查後端服務
curl -s http://localhost:8888/here4help/backend/api/auth/login.php

# 檢查 iOS 模擬器網路
xcrun simctl spawn booted ping localhost
```

#### **3. Web 平台無法連接**
```bash
# 檢查後端服務
curl -s http://localhost:8888/here4help/backend/api/auth/login.php

# 檢查瀏覽器網路
open http://localhost:8888/here4help/backend/api/auth/login.php
```
