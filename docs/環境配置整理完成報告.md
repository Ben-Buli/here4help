## 🔧 環境配置載入機制

### **統一載入器** (`env/env_loader.php`)
```php
// 自動載入生產環境配置
EnvLoader::load('production');

// 取得環境變數
$apiUrl = EnvLoader::get('API_BASE_URL');
$dbHost = EnvLoader::get('DB_HOST');
```

### **Backend 載入器** (`backend/config/env_loader.php`)
```php
// 優先從統一環境配置目錄載入
$envPath = dirname(dirname(__DIR__)) . '/env/production.env';
if (file_exists($envPath)) {
    $path = $envPath;
} else {
    // 回退到 backend/.env
    $path = dirname(__DIR__) . '/.env';
}
```

## 📋 環境切換指南

### **切換到開發環境**
```bash
# 1. 更新符號連結
cd backend && ln -sf ../env/development.env .env
cd admin && ln -sf ../env/development.env .env
cd admin/frontend && ln -sf ../../env/development.env .env

```

### **切換到測試環境**

```bash

# 2. 使用生產環境的 Flutter Web 配置
cp env/flutter_web_production.json build/web/assets/env.json
```

## 🔄 維護指南

### **新增環境變數**
1. 在 `env/production.env` 中新增變數
2. 在 `env/development.env` 和 `env/staging.env` 中新增對應變數
3. 如果是公開資訊，在 `env/flutter_web_*.json` 中新增

### **修改環境配置**
1. 直接修改 `env/*.env` 檔案
2. 所有引用會自動更新（透過符號連結）
3. 重新載入環境配置即可生效

### **備份環境配置**
```bash
# 備份統一環境配置
tar -czf env_backup_$(date +%Y%m%d).tar.gz env/
```
