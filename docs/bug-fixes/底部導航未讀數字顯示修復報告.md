# 底部導航未讀數字顯示修復報告

## 🐛 問題描述

底部導航 Chat 圖示的未讀數字統計只顯示 "99+" 或小圓點，沒有完整顯示兩個分頁的總計數字。

### **問題現象**
- 未讀數字 1-9：只顯示小圓點，不顯示具體數字
- 未讀數字 10-99：只顯示小圓點，不顯示具體數字
- 未讀數字 >99：顯示 "99+"
- 缺少完整的數字顯示功能

## 🔍 問題分析

### **根本原因**

#### **1. 顯示邏輯不完整**
```dart
// 問題：只處理 99+ 的情況，其他情況只顯示小圓點
child: totalUnread > 99
    ? const Center(
        child: Text(
          '99+',
          style: TextStyle(
            color: Colors.white,
            fontSize: 7,
            fontWeight: FontWeight.bold,
          ),
        ),
      )
    : null, // ❌ 其他情況只顯示小圓點
```

**問題**：當未讀數字在 1-99 範圍內時，只顯示小圓點而不顯示具體數字。

#### **2. 容器尺寸固定**
```dart
// 問題：容器尺寸固定，無法適應不同數字長度
width: totalUnread > 99 ? 16 : 8,
height: totalUnread > 99 ? 16 : 8,
```

**問題**：容器尺寸固定，無法根據數字長度動態調整。

#### **3. 缺少數字顯示邏輯**
```dart
// 問題：缺少 10-99 範圍的數字顯示邏輯
// 只有 99+ 和 null（小圓點）兩種情況
```

**問題**：缺少中間範圍（10-99）的數字顯示處理。

## 🔧 修復方案

### **1. 完善顯示邏輯**

#### 修改檔案：`lib/layout/app_scaffold.dart`

**執行內容**：
- 添加 10-99 範圍的數字顯示邏輯
- 動態調整容器尺寸
- 優化字體大小和樣式

**程式碼變更**：
```dart
return Stack(
  clipBehavior: Clip.none,
  children: [
    const Icon(Icons.message),
    if (totalUnread > 0)
      Positioned(
        right: totalUnread > 99 ? -2 : 0,
        top: totalUnread > 99 ? -2 : 0,
        child: Container(
          width: totalUnread > 99 ? 16 : (totalUnread > 9 ? 12 : 8),
          height: totalUnread > 99 ? 16 : (totalUnread > 9 ? 12 : 8),
          decoration: BoxDecoration(
            color: Theme.of(context).colorScheme.error,
            shape: BoxShape.circle,
          ),
          child: totalUnread > 99
              ? const Center(
                  child: Text(
                    '99+',
                    style: TextStyle(
                      color: Colors.white,
                      fontSize: 7,
                      fontWeight: FontWeight.bold,
                    ),
                  ),
                )
              : totalUnread > 9
                  ? Center(
                      child: Text(
                        totalUnread.toString(),
                        style: TextStyle(
                          color: Colors.white,
                          fontSize: 8,
                          fontWeight: FontWeight.bold,
                        ),
                      ),
                    )
                  : null,
        ),
      ),
  ],
);
```

### **2. 添加詳細調試信息**

**執行內容**：
- 添加顯示類型的調試日誌
- 提供完整的未讀數據分析

**程式碼變更**：
```dart
debugPrint('  - 最終未讀總數: $totalUnread');
debugPrint('  - 顯示類型: ${totalUnread > 99 ? "99+" : totalUnread > 9 ? "數字" : "小圓點"}');
```

## 📊 修復效果

### **功能改善**
- ✅ **完整數字顯示**：1-99 範圍內顯示具體數字
- ✅ **動態容器尺寸**：根據數字長度自動調整容器大小
- ✅ **三種顯示模式**：
  - 1-9：小圓點
  - 10-99：數字
  - >99：99+
- ✅ **詳細調試信息**：提供完整的顯示類型分析

### **技術特點**
- ✅ **響應式設計**：容器尺寸根據內容動態調整
- ✅ **字體優化**：不同範圍使用不同的字體大小
- ✅ **視覺一致性**：保持與原有設計風格一致
- ✅ **調試友好**：提供詳細的調試信息

| **10-99** | 數字 | 12x12 | 8px |

## 🎯 技術要點
