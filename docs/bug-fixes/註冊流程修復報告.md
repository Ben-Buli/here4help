# 註冊流程修復報告

## 修復問題

### 1. JSON 解析錯誤處理 ✅

**問題描述**：
- 前端在 `jsonDecode(response.body)` 時，伺服器實際回傳的是 HTML（開頭是 `<br /><b>` 的 PHP 錯誤頁/404 頁）而不是 JSON
- 導致 `FormatException: Unexpected token '<'` 錯誤

**修復方案**：
1. **檢查回應格式**：在解析 JSON 前檢查回應是否為 HTML 錯誤頁面
2. **安全的 JSON 解析**：使用 try-catch 包裹 `jsonDecode`
3. **友善的錯誤訊息**：提供更清楚的錯誤提示

**修復代碼**：
```dart
// 🔧 修復：檢查回應是否為 HTML 錯誤頁面
if (response.body.trim().startsWith('<') || 
    response.body.contains('<br />') || 
    response.body.contains('<html>')) {
  debugPrint('❌ 伺服器回傳 HTML 錯誤頁面: ${response.body.substring(0, 100)}...');
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(
      content: Text('Server error (HTTP ${response.statusCode}): Please try again later'),
      backgroundColor: Theme.of(context).colorScheme.error,
    ),
  );
  return false;
}

// 🔧 修復：安全的 JSON 解析
Map<String, dynamic> responseData;
try {
  responseData = jsonDecode(response.body);
} catch (jsonError) {
  debugPrint('❌ JSON 解析失敗: $jsonError');
  debugPrint('❌ 回應內容: ${response.body}');
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(
      content: const Text('Invalid server response format. Please try again.'),
      backgroundColor: Theme.of(context).colorScheme.error,
    ),
  );
  return false;
}
```

### 2. 註冊成功後跳轉問題 ✅

**問題描述**：
- 點擊 'Complete Registration' 按鈕後，即使成功註冊會員，也不會前往學生證頁面

**根本原因分析**：
- 後端 `register.php` 的 `Response::success()` 參數順序錯誤
- 前端無法正確取得 `user_id`，導致學生證頁面驗證失敗

**修復方案**：
1. **修正後端回應格式**：調整 `Response::success()` 參數順序
2. **保存 user_id**：註冊成功後將 `user_id` 保存到 `SharedPreferences`
3. **完善驗證邏輯**：學生證頁面檢查 `user_id` 是否存在

**修復代碼**：

**後端修復** (`backend/api/auth/register.php`)：
```php
// 修復前
Response::success('User registered successfully', [
    'user_id' => $userId,
    'email' => $email,
    'status' => 'active'
]);

// 修復後
Response::success([
    'user_id' => $userId,
    'email' => $email,
    'status' => 'active'
], 'User registered successfully');
```

**前端修復** (`lib/auth/pages/signup_page.dart`)：
```dart
if (response.statusCode == 200 && responseData['success'] == true) {
  // 🔧 修復：保存 user_id 到 SharedPreferences
  final userData = responseData['data'] as Map<String, dynamic>?;
  final userId = userData?['user_id'];
  
  if (userId != null) {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('signup_user_id', userId.toString());
    debugPrint('✅ 用戶註冊成功，user_id: $userId');
  }
  
  // ... 成功訊息和跳轉邏輯
}
```

### 3. 學生證頁面 user_id 關聯 ✅

**問題描述**：
- 學生證頁面無法正確取得新註冊會員的 `users.id`
- `student_verifications.user_id` 關聯錯誤

**修復方案**：
1. **增強資料驗證**：檢查 `user_id` 是否存在於 `SharedPreferences`
2. **修改上傳邏輯**：使用 `user_id` 而非 `email` 作為主要識別
3. **後端兼容性**：支援同時接受 `user_id` 和 `email`（向後兼容）

**修復代碼**：

**前端修復** (`lib/auth/pages/student_id_page.dart`)：
```dart
Future<void> _checkRegistrationData() async {
  final prefs = await SharedPreferences.getInstance();
  
  // 檢查是否有完整的註冊資料
  final hasBasicInfo = prefs.getString('signup_full_name') != null &&
      prefs.getString('signup_email') != null &&
      prefs.getString('signup_password') != null;
  
  final hasPaymentCode = prefs.getString('signup_payment_code') != null;
  
  // 🔧 新增：檢查是否有 user_id（註冊成功後才會有）
  final hasUserId = prefs.getString('signup_user_id') != null;
  
  setState(() {
    hasAllData = hasBasicInfo && hasPaymentCode && hasUserId;
  });
  
  if (!hasAllData) {
    String errorMessage = 'Please complete the registration form first';
    if (hasBasicInfo && hasPaymentCode && !hasUserId) {
      errorMessage = 'Registration incomplete. Please register again.';
    }
    
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text(errorMessage),
        backgroundColor: Colors.orange,
      ),
    );
    context.go('/signup');
  }
}
```

**後端修復** (`backend/api/auth/upload-student-id.php`)：
```php
// 🔧 修復：優先使用 user_id，如果沒有則使用 email 查找
if (!empty($userId)) {
    // 直接使用 user_id
    $user = $db->fetch("SELECT id, email FROM users WHERE id = ?", [$userId]);
    if (!$user) {
        Response::error('User not found with provided user_id');
        exit;
    }
    $userId = $user['id'];
    $userEmail = $user['email'];
    error_log("[upload-student-id] 使用 user_id: $userId, email: $userEmail");
} elseif (!empty($email)) {
    // 使用 email 查找（向後兼容）
    $user = $db->fetch("SELECT id FROM users WHERE email = ?", [$email]);
    if (!$user) {
        Response::error('User not found with provided email');
        exit;
    }
    $userId = $user['id'];
    error_log("[upload-student-id] 使用 email 查找到 user_id: $userId");
} else {
    Response::error('Either user_id or email is required');
    exit;
}
```

## 完整註冊流程

### 修復後的流程：

1. **用戶填寫註冊表單** → 點擊 "Complete Registration"
2. **前端驗證** → 表單驗證通過
3. **發送註冊請求** → 調用 `backend/api/auth/register.php`
4. **後端處理**：
   - 驗證必填欄位
   - 檢查 email 是否已存在
   - 創建用戶記錄
   - 回傳 `user_id`、`email`、`status`
5. **前端處理成功回應**：
   - 保存 `user_id` 到 `SharedPreferences`
   - 保存其他註冊資料到 `SharedPreferences`
   - 跳轉到 `/signup/student-id`
6. **學生證頁面**：
   - 驗證註冊資料完整性（包含 `user_id`）
   - 用戶上傳學生證
   - 使用 `user_id` 關聯到 `student_verifications` 表
   - 清理暫存資料，跳轉到登入頁面

### 資料流向：

```
註冊頁面 (signup_page.dart)
    ↓ (註冊成功)
SharedPreferences 暫存
    ├─ signup_user_id: "123"
    ├─ signup_email: "user@example.com"
    ├─ signup_full_name: "John Doe"
    └─ ... (其他註冊資料)
    ↓
學生證頁面 (student_id_page.dart)
    ↓ (上傳學生證)
student_verifications 表
    ├─ user_id: 123 (關聯到 users.id)
    ├─ school_name: "台灣大學"
    ├─ student_name: "John Doe"
    ├─ student_id: "B12345678"
    ├─ image_path: "student_id_123_1640995200.jpg"
    └─ status: "pending"
```
