# 底部導航未讀統計權限修復報告

## 🐛 問題描述

用戶 `elies818@gmail.com` 登入後，只有一筆任務且尚未有任何聊天室存在，但底部導航欄卻顯示 99+ 未讀訊息的標記。

### **問題現象**
- 新用戶或無聊天記錄的用戶顯示錯誤的 99+ 未讀標記
- 底部導航欄統計了不屬於當前用戶的聊天室未讀數
- 未讀數字統計不準確，包含了其他用戶的未讀消息

## 🔍 問題分析

### **根本原因**

#### **1. 缺少用戶權限檢查**
```dart
// 錯誤的代碼：直接遍歷所有聊天室的未讀數
for (final count in chatProvider.unreadByRoom.values) {
  totalUnread += count; // ❌ 統計了所有聊天室，包括其他用戶的
}
```

**問題**：底部導航欄直接遍歷 `ChatListProvider.unreadByRoom` 中的所有聊天室未讀數，沒有區分哪些聊天室屬於當前用戶。

#### **2. 數據來源問題**
雖然後端 API `unread_by_tasks.php` 正確按用戶 ID 進行篩選，但前端可能：
- 接收到了測試數據或緩存數據
- Socket.IO 返回了全域的未讀數據
- 前端沒有正確過濾用戶權限

### **數據流程問題**
```
修復前：
Socket.IO → 返回所有房間未讀數 → ChatListProvider.unreadByRoom → 底部導航欄直接求和

修復後：
Socket.IO → 返回所有房間未讀數 → ChatListProvider.unreadByRoom → 底部導航欄按用戶權限篩選求和
```

## 🔧 修復方案

### **1. 添加用戶權限檢查**

#### 修改檔案：`lib/layout/app_scaffold.dart`

**執行內容**：
- 添加用戶權限檢查邏輯
- 只統計當前用戶有權限的聊天室未讀數
- 添加調試日誌來追蹤未讀數據

**程式碼變更**：
```dart
@override
Widget build(BuildContext context) {
  return Consumer<ChatListProvider>(
    builder: (context, chatProvider, child) {
      // 計算當前用戶有權限的聊天室未讀數總和
      int totalUnread = 0;

      // 獲取當前用戶信息
      final userService = Provider.of<UserService>(context, listen: false);
      final currentUserId = userService.currentUser?.id.toString();

      // 調試：打印未讀數據
      debugPrint('🔍 [底部導航] 調試未讀數據:');
      debugPrint('  - 當前用戶 ID: $currentUserId');
      debugPrint('  - 總聊天室數: ${chatProvider.unreadByRoom.length}');
      debugPrint('  - 未讀數據: ${chatProvider.unreadByRoom}');

      if (currentUserId != null) {
        // 只統計當前用戶有權限的聊天室
        for (final entry in chatProvider.unreadByRoom.entries) {
          final roomId = entry.key;
          final count = entry.value;
          
          // 檢查聊天室是否屬於當前用戶
          if (_isUserAuthorizedForRoom(roomId, currentUserId)) {
            totalUnread += count;
            debugPrint('  - 有權限的聊天室: $roomId = $count');
          } else {
            debugPrint('  - 無權限的聊天室: $roomId = $count (已排除)');
          }
        }
      }

      debugPrint('  - 最終未讀總數: $totalUnread');

      return Stack(
        clipBehavior: Clip.none,
        children: [
          const Icon(Icons.message),
          if (totalUnread > 0)
            Positioned(
              right: totalUnread > 99 ? -2 : 0,
              top: totalUnread > 99 ? -2 : 0,
              child: Container(
                width: totalUnread > 99 ? 16 : 8,
                height: totalUnread > 99 ? 16 : 8,
                decoration: BoxDecoration(
                  color: Theme.of(context).colorScheme.error,
                  shape: BoxShape.circle,
                ),
                child: totalUnread > 99
                    ? const Center(
                        child: Text(
                          '99+',
                          style: TextStyle(
                            color: Colors.white,
                            fontSize: 7,
                            fontWeight: FontWeight.bold,
                          ),
                        ),
                      )
                    : null,
              ),
            ),
        ],
      );
    },
  );
}

/// 檢查用戶是否有權限訪問特定聊天室
bool _isUserAuthorizedForRoom(String roomId, String currentUserId) {
  // 這裡需要根據聊天室 ID 的格式來判斷用戶權限
  // 假設聊天室 ID 格式為: "room_${taskId}_${creatorId}_${participantId}"
  // 或者 "room_${taskId}_${userId1}_${userId2}"
  
  try {
    // 解析聊天室 ID
    if (roomId.startsWith('room_')) {
      final parts = roomId.split('_');
      if (parts.length >= 4) {
        // 格式: room_taskId_creatorId_participantId
        final creatorId = parts[2];
        final participantId = parts[3];
        
        // 檢查當前用戶是否為創建者或參與者
        return creatorId == currentUserId || participantId == currentUserId;
      }
    }
    
    // 如果無法解析，預設為無權限
    return false;
  } catch (e) {
    // 解析失敗，預設為無權限
    return false;
  }
}
```
