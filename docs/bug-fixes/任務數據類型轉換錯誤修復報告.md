# 任務數據類型轉換錯誤修復報告

## 📋 **問題描述**

在 `_ConfirmPayDialog` 組件中，當嘗試計算手續費時出現類型錯誤：

```
TypeError: "500": type 'String' is not a subtype of type 'int'
```

**錯誤位置**: `lib/chat/pages/chat_detail_page.dart:4337:26`

**錯誤原因**: 任務數據中的 `reward_point` 字段是字符串類型（如 "500"），但代碼期望的是整數類型。

## 🔍 **問題分析**

### 1. **數據來源問題**
- 後端 API 返回的任務數據中，`reward_point` 可能是字符串格式
- 前端代碼直接使用 `widget.task!['reward_point'] ?? 0` 假設為整數
- 當傳遞給 `WalletService.calculateFee()` 時發生類型不匹配

### 2. **影響範圍**
- `_calculateFee()` 方法
- `_buildFeeDetails()` 方法  
- `_submitPayment()` 方法
- 所有使用 `reward_point`、`creator_id`、`participant_id` 的地方

## 🔧 **修復方案**

### 1. **創建安全的類型轉換方法**

```dart
/// 安全地將任務數據中的數值轉換為整數
int _safeParseInt(dynamic value, {int defaultValue = 0}) {
  if (value == null) return defaultValue;
  if (value is int) return value;
  if (value is String) return int.tryParse(value) ?? defaultValue;
  if (value is double) return value.toInt();
  return defaultValue;
}
```

### 2. **更新所有相關方法**

#### **修復前**:
```dart
final rewardPoints = widget.task!['reward_point'] ?? 0;
```

#### **修復後**:
```dart
final rewardPoints = _safeParseInt(widget.task!['reward_point']);
```

### 3. **統一處理所有數值字段**

```dart
// 修復前
final rewardPoints = widget.task!['reward_point'] ?? 0;
final creatorId = widget.task!['creator_id'] ?? 0;
final participantId = widget.task!['participant_id'] ?? 0;

// 修復後
final rewardPoints = _safeParseInt(widget.task!['reward_point']);
final creatorId = _safeParseInt(widget.task!['creator_id']);
final participantId = _safeParseInt(widget.task!['participant_id']);
```

## 🔄 **預防措施**

### 1. **後端數據標準化**
- 建議後端 API 統一返回整數格式的數值字段
- 在 API 文檔中明確指定數據類型

### 2. **前端防護**
- 所有從 API 獲取的數值字段都使用 `_safeParseInt()` 處理
- 添加數據驗證和錯誤日誌

### 3. **類型定義**
- 考慮使用強類型模型類替代 `Map<String, dynamic>`
- 定義明確的數據結構接口
